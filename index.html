2) Segment-wise Carriageway — Width, Surface, Status

Chainage फक्त मीटरमध्ये भरा: 0000 → 0500 → 1000. Width, surface किंवा status पैकी काहीही बदलले की नवीन segment करा. Surface (BT / CC / WBM / Earthen) नुसार KML मधील carriageway चा रंग बदलतो. Status (Good / Bad / Work in progress / DLP / Missing) रस्त्याच्या डाव्या बाजूला वेगळ्या रंगीत रेषेने दिसतो. प्रत्येक segment वर (लांब segment असल्यास साधारण दर 1 km वर) width · surface · status चे label दिसते.

BTCCWBMEarthenGoodBadWIPDLPMissing

प्रत्येक segment चे तीनही inputs भरा.

CSV columns: from_chainage,to_chainage,width_m,surface,status,remark,row_m. उदाहरण: 0000,0500,7,BT,Good,,30. row_m रिकामा ठेवल्यास वरचा default ROW वापरला जातो. जुन्या CSV पण चालतात. CSV मध्येही chainage फक्त मीटरमध्ये ठेवा; + किंवा km वापरू नका. एकमेकांवर येणारे segments स्वीकारले जाणार नाहीत.

3) Location-wise Site Photos

Location फक्त GPS मधून घेतले जाते: Camera फोटोसाठी सध्याचे GPS, Gallery फोटोसाठी फोटोमध्ये साठवलेले GPS (EXIF). Lat / Long हाताने भरण्याचा पर्याय नाही. फोटोमध्ये GPS नसेल (उदा. WhatsApp वरून आलेला फोटो), तर फोटो रस्त्यावरील chainage वर ठेवता येतो.

Location: अजून मिळाले नाही
अजून फोटो जोडलेले नाहीत.

मोबाइलवर GPS साठी Location permission द्या. HTTPS वर वापर अधिक सोयीचा; local HTML मधील GPS उपलब्धता browser नुसार बदलू शकते. GPS मिळाले नाही तर chainage वापरा. फोटो device वर प्रक्रिया होतात; upload केले जात नाहीत.

4) Junction / गाव / Road crossing

रस्त्यावरील महत्त्वाची ठिकाणे chainage नुसार भरा: junction / फाटा, गाव, दुसऱ्या रस्त्याचे crossing, रेल्वे फाटक. KML मध्ये प्रत्येक ठिकाणी रंगीत चिन्ह आणि रस्त्याला आडवी रेषा दिसेल. Strip chart वर क्रमांकासह खूण आणि खाली यादी येईल. Structures CSV मधील culvert / bridge सुद्धा strip chart वर दिसतात.

अजून ठिकाणे जोडलेली नाहीत.

CSV columns: chainage,type,name,remark. Type: Junction / Village / Road crossing / Railway / Other (गाव, चौक, फाटा, रेल्वे असे मराठी शब्दही चालतात).

काम जतन करा

काम या browser मध्ये आपोआप जतन होते (autosave) — पान बंद झाले तरी पुन्हा उघडल्यावर परत मिळेल. तरीही दुसऱ्या फोनवर / computer वर नेण्यासाठी किंवा सुरक्षिततेसाठी Project Backup डाउनलोड करा. त्यात निवडलेला रस्ता, फोटो, locations, widths आणि settings राहतील. पुढच्या वेळी तेच backup उघडून काम पुढे करता येईल.
